# Aholo 黑客松 报名信息（需本人完成验证）

> 报名入口：https://www.aholo3d.cn/hackathon/register
> 截止：2026-11-19 19:00（北京）— 报名与作品提交同一天截止，别只记交作品忘了报名。

## 我（Agent）能做的
- 打开报名页并导航到表单；
- 填写所有不需要验证码的字段（昵称、密码、同意协议等）；
- 在验证码那一步停下，交给你输入。

## 我（Agent）做不了、必须你本人做的
- **手机号 / 邮箱 + 验证码**：第三方平台真人验证，我收不到码。
- **真实姓名 / 身份证明**（若获奖阶段才需，初始报名通常不收证件号）。

## 报名页预期字段（SPA 页面 WebFetch 抓不到，以实际页面为准）
- 手机号 或 邮箱（二选一注册 Aholo 账号）
- 短信 / 邮件验证码
- 登录密码
- 昵称 / 显示名
- ☑ 同意《用户协议》《隐私政策》（机器人参赛须知）
- 提交按钮：通常为「注册并报名」/「立即报名」

## 你需要提供给我的（任选其一）
- A. 你的手机号 或 邮箱，并同意由我代填表单，验证码你来输入；
- B. 你自己注册报名，我只负责后续「创建团队 / 提交选题 / 生成资产 / 出报告」。

## 报名后动作（仍需你确认）
1. 进入「我的参赛」→ 创建团队（单人即一人团队）→ 创建项目。
2. 提交选题：项目名 **StoryLight3D**，简介见 concept.md。
3. 提交选题后解锁团队积分（助力 Lux3D 生成额度）。
4. 团队锁定时间：2026-11-19 19:00，之前可调整成员。

## 注意事项
- 一个赛事账号只能绑定一个 Aholo 账号；用本人真实信息，勿重复注册。
- 报名成功即发放首笔算力积分；积分无现金价值、有有效期。
- 未成年人需监护人同意（你应已成年，忽略此项）。
