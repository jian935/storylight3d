StoryLight3D · 提交用简介（可直接复制）
========================================

【精简版 · 约110字】
StoryLight3D 是一个「故事即 3D 场景」的 Web 创作工具。作者在散文里用轻量标记内联 3D 实体（如 [[名称:类型:描述]]），工具解析后逐个调用 Aholo Lux3D 文生 3D 生成资产，并渲染成可旋转、可点击聚焦的交互式 3D 场景。Lux3D 贯穿「文本→3D 资产→场景→报告书对比」全链路，是核心引擎。

【标准版 · 约240字】
StoryLight3D 是一款让「写作即造物」的 Web 应用。创作者用轻量标记语法在故事散文里内联描述角色、生物、道具与场景（例如 [[小精灵:character:发光的森林精灵]]），系统自动解析实体、逐个调用 Aholo Lux3D 文生 3D 生成模型，并拼装成一个可自由旋转、点击聚焦的交互式 3D 场景，一键在线分享。
项目以 Lux3D 为唯一 3D 内容引擎，覆盖「文本解析 → Lux3D 文生 3D → 资产进入场景 → 报告书资产迭代对比」的完整链路；内置三套演示故事（精灵森林 / 轨道机甲 / 云雾茶舍）可直接体验。作品兼具趣味演示与叙事创作双重价值，并配套小红书传播与开源代码。
