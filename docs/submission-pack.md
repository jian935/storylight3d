## 1. 简介（直接复制）

**精简版（约 110 字，适合字数受限的输入框）**

> StoryLight3D 是一个「故事即 3D 场景」的 Web 创作工具。作者在散文里用轻量标记内联 3D 实体（如 `[[名称:类型:描述]]`），工具解析后逐个调用 Aholo Lux3D 文生 3D 生成资产，并渲染成可旋转、可点击聚焦的交互式 3D 场景。Lux3D 贯穿「文本→3D 资产→场景→报告书对比」全链路，是核心引擎。

**标准版（约 240 字，适合简介大段）**

> StoryLight3D 是一款让「写作即造物」的 Web 应用。创作者用轻量标记语法在故事散文里内联描述角色、生物、道具与场景（例如 `[[小精灵:character:发光的森林精灵]]`），系统自动解析实体、逐个调用 Aholo Lux3D 文生 3D 生成模型，并拼装成一个可自由旋转、点击聚焦的交互式 3D 场景，一键在线分享。
>
> 项目以 Lux3D 为唯一 3D 内容引擎，覆盖「文本解析 → Lux3D 文生 3D → 资产进入场景 → 报告书资产迭代对比」的完整链路；内置三套演示故事（精灵森林 / 轨道机甲 / 云雾茶舍）可直接体验。作品兼具趣味演示与叙事创作双重价值，并配套小红书传播与开源代码。

## 3. 技术栈与实现（可直接贴到"详细描述"）

- **前端**：原生 ES Modules + Three.js（已本地 vendor，去 CDN，离线可跑）；OrbitControls / GLTFLoader / PMREM。
- **3D 生成**：Aholo Lux3D 文生 3D（G1-Turbo），输出带 PBR 材质的 GLB；共生成 **10 个真实资产**。
- **装配策略**：按实体类型归一化目标尺寸（角色 2.3 / 道具 2.0 / 场景 3.6），真实占地宽度累加布局，自动取景。
- **稳定性**：三档加载——预生成 GLB → Lux3D 实时生成 → 占位几何体，逐级回退，永不白屏。
- **零后端**：静态站即可运行；密钥不进前端；部署成本≈0。

## 7. 常见坑

1. **Demo 链接漏 sharecode** → 被平台保护机制拦截，评委打不开。
2. **源码链接指向旧提交** → 新视频/叙事不在仓库里，等于没换。
3. **视频体积超限** → 改用 1.5MB 的 web.mp4；若要求公开链接（B站/YouTube），需本人上传。
4. **提交后大改仓库结构** → 路径变化导致链接失效；提交后只做文档级小改。
5. **把作品集落地页当作品交** → 评委看不到"可运行的产品"，主体错位。
