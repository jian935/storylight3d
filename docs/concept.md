# StoryLight3D · 项目构思

> Aholo 全球 3D AI 黑客松参赛作品（群核科技）
> 参赛必须使用 Aholo Lux3D，并让它承担核心 3D 内容 / 关键创作流程。

## 一句话定位
**StoryLight3D 是一个「故事即 3D 场景」的创作工具**：作者用一种轻量 DSL
在散文里内联标记 3D 实体（`[[名称:类型:描述]]`），工具解析后**逐个调用 Aholo Lux3D
文生 3D** 生成资产，并渲染成一个可旋转、可点击聚焦的交互式 3D 场景。

## 为什么契合赛事（对应评审维度）
- **30% 群核技术栈应用**：Lux3D 是整条流水线的核心——故事文本 → Lux3D 文生 3D →
  资产进入场景 → 报告书资产迭代对比截图，全链路以 Lux3D 为引擎，不是装饰。
- **25% 作品有趣程度**：写故事就能"看见"角色/场景立起来，天然适合演示视频的趣味呈现。
- **20% 创新性**：把 3D 生成包装成「写作 DSL + 叙事预览」，区别于常见的"上传图出模型"玩法。
- **20% 完成度**：Web 应用可直接运行（在线链接）+ 真实运行视频，材料与成果匹配。
- **5% 传播**：小红书带 `#Aholo黑客松` 发布。

## 技术架构
```
作者散文（含 [[标签]]）
      │  parseStory()
      ▼
实体列表 [{name, type, prompt}]
      │  对每个实体
      ▼
Aholo Lux3D 文生 3D  (labs.aholo3d.cn API / MCP)
      │  资产 URL (GLB/GLTF)
      ▼
Three.js 场景：占位布局 + 点击聚焦 + 轨道控制
      │
  在线发布（sites / cloud-service）
```

- 前端：原生 ES Module + Three.js（OrbitControls / GLTFLoader），无构建步骤。
- Lux3D 接入：`web/lux3d.js`，已封装「提交任务 → 轮询 → 取回资产 URL」；
  未配置 Key 时自动回退**占位模型**，保证完整交互流程可演示。
- 类型支持：`character`(角色) / `creature`(生物) / `prop`(道具) / `scene`(场景建筑)。

用同一故事跑三版，截对比图放入报告书。
