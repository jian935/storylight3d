# StoryLight3D · 闭环演示视频（脚本 + 制作说明）

> 成片：`deliverables/video/StoryLight3D-闭环演示.mp4`
> 规格：1280×720 / 30fps / 47.4s / 中文旁白 + 逐词高亮字幕
> 定位：作品集「视频闭环」——用**真实运行画面**演示 写故事 → 生成 → 3D → 交互 → 切换 → 分享 的完整闭环

## 一、和旧版演示视频的区别

| | 旧版 `StoryLight3D-演示视频.mp4` | 新版 `StoryLight3D-闭环演示.mp4` |
|---|---|---|
| 画面来源 | 报告截图做 Ken-Burns 平移缩放 | **应用真实运行录屏**（CDP screencast） |
| 是否闭环 | 更像功能幻灯片 | 写/生成/交互/切换/收尾，一条连续路径 |
| 帧率 | 30fps（静态图补帧） | 30fps（真实渲染，GPU 采集） |
| 用途 | 黑客松提交 | 作品集首页 / 面试开场 |

## 三、制作流水线

```
scripts/record_loop.mjs        # 1. CDP 录制真实运行画面
   ├─ 无头 Edge + D3D11 硬件渲染（软件渲染仅 ~3fps）
   ├─ Page.startScreencast（jpeg q82，每 2 帧取 1 ≈ 30fps）
   ├─ 页面内 window.__sl3d 驱动运镜（orbit / zoom），非模拟鼠标
   └─ 输出 loop/frames/*.jpg + loop/timeline.json（帧时间戳 + 分段标记）

scripts/build_loop_video.py    # 2. 配音 + 重采样 + 字幕 + 成片
   ├─ 每段 edge-tts 中文旁白（zh-CN-XiaoxiaoNeural，带重试）
   ├─ 按旁白时长把该段真实帧按时间重采样（硬链接成连续序列）
   ├─ 开场标题卡用 PIL 生成（真正的 JPEG）
   ├─ 逐词高亮 ASS（字/词权重均摊）
   └─ ffmpeg 编码 → 混音 → 烧字幕 → 成片
```

### 复现命令

```bash
# 1) 起静态服务（真实 GLB 资产需在 web/assets/generated/）
cd web && python -m http.server 8080

# 2) 录制（约 60s，输出 1600+ 帧）
node scripts/record_loop.mjs

# 3) 合成（约 1-2 分钟）
python scripts/build_loop_video.py
```

## 四、踩过的坑（下次别再踩）

1. **软件渲染只有 ~3fps**：`--use-angle=swiftshader` 下 rAF 3.15fps，录出来像幻灯片。
   改用 `--use-angle=d3d11` 后 rAF 60fps、screencast 59fps。
2. **image2 编码出 2.4s 起始偏移**：`start_time=2.4` 会让播放器跳过开场。
   编码时加 `-vf setpts=PTS-STARTPTS` 归零。
3. **PNG 改名 `.jpg` 会整段丢失**：开场标题卡若存成 PNG 却命名 `.jpg` 混进 JPEG 序列，
   ffmpeg 会跳过这 72 帧（成片少 2.4s）。必须用 PIL 存真 JPEG。
4. **硬链接省空间**：重采样会重复引用同一帧，用 `os.link` 生成连续序列，不额外占盘。
5. **旁白时长 ≠ 录制时长**：不要按帧数拼接，按**旁白时长重采样**，否则音画会漂。

## 五、可调参数

- `record_loop.mjs`：视口 `W/H`、`quality`、`everyNthFrame`、各段 `sleep`。
- `build_loop_video.py`：`FPS`、`GAP`（段间停顿）、`TITLE_DUR`（开场标题时长）、`NARRATION` 文案。
